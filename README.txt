Automatización de Informes en Python

Este proyecto genera informes PDF profesionales a partir de archivos CSV, utilizando Python.
Nació como un ejercicio práctico para aprender automatización, manejo de datos y generación de reportes, aplicándolo a situaciones reales y simples.

¿Qué hace el proyecto?
-Lee un archivo CSV con registros.
-Procesa los datos con pandas.
-Genera un informe PDF moderno y presentable.
-Resume la información de forma clara (totales, promedios, conclusiones).
-Usa una plantilla visual pensada para comunicación institucional.

Tecnologías usadas:

Python

pandas

reportlab (PDF)


Es un proyecto que uso en mi vida personal, particularmente lo adapté para registrar y analizar mi aprendizaje de inglés, separando actividades como speaking, 
listening, reading y writing para poder llevar registro de mi estudio.
